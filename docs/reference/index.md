# Reference

Auto-generated and hand-maintained reference material for atomc's public surfaces.

- **[IR schema browser](/reference/ir-schema)** — interactive tree over the generated
  `system_ir.schema.json`, straight from the `core-ir` Pydantic models.
- **[CLI](/reference/cli)** — commands and flags for the `atomc` binary (*planned*, Phase 3).
- **[RPC methods](/reference/rpc)** — the `atomcd` JSON-RPC/WebSocket surface (*frozen draft*, Phase 2).
- **[Packages](/reference/packages/)** — every workspace README, mirrored by `docs:sync`.

::: info Source of truth
Field-level IR detail lives in the frozen
[IR schema contract](/architecture/contracts/ir-schema); RPC detail lives in the
[RPC contract](/architecture/contracts/rpc). These reference pages render or summarise those, but the
contracts win if they ever disagree.
:::
