# Plan & status

This section mirrors the project's single source of truth, [`PLAN.md`](https://github.com/dtmirizzi/atomc/blob/main/PLAN.md),
so the roadmap and the docs never drift.

- **[Master plan](/plan/master)** — the full plan: decisions log, version matrix, contracts, testing
  model, work breakdown and risks.

## Phase overview

| Phase | Name | Focus |
| ----- | ---- | ----- |
| 0 | Environment | Install and verify all toolchains (`scripts/bootstrap.sh`, `doctor.py`) |
| 1 | Monorepo & IR | Core IR (Py + TS), contract tests, CI/release, docs site, examples |
| 2 | SDK & daemon | Plugin SDK, `atomcd`, warm kernels, daemon client, RPC tests |
| 3 | Harness & CLI | CLI, swarm state machine, agents, converge, Studio |
| 4 | Hardware plugins | atopile, Renode, QMK, cad-jig, e2e vertical slice |
| 5 | Supply chain | Sourcing adapters, optimizer, fab quotes, orders |
| 6 | Hardening | Real prototype order, bring-up, Homebrew tap, `v1.0.0` |
